# Command Centre

## What it is
The fort's headquarters area where defenders coordinated gun batteries. Sources mention a command centre and later use as a Japanese command post. No photo is labeled as the command centre.

## History (draft, 2 to 4 sentences)
British engineers built the fort with gun bays, anti-aircraft positions, barracks, a cookhouse and a command centre (the 2011 blog and WARMAP). The Japanese reused the site as a command post and naval base after December 1941.

## Interesting facts (draft)
- Garrison included British, Malay and Sikh soldiers (WARMAP).
- The British expected a naval attack, but Japanese forces attacked overland in December 1941 and the island fell quickly (WARMAP).
- Exact location of the command room is unknown (needs site visit).
